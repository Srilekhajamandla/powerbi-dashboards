# 🌍 Global Retail Sales Dashboard  | Power BI 
This repository showcases an end-to-end **Global Retail Sales Analytics Dashboard** built using **Power BI**. 

The solution enables business leaders to track sales performance, profitability, customer behavior, operational metrics, and product-level trends across global regions.

## 🚀 Key Insights Delivered

### ✔️ Sales & Profitability Overview

- Total Sales: 9.48M

- Total Profit: 1.09M

- Monthly sales trend with seasonality patterns

- Profit Margin % and Return Rate %

- Sales vs Target analysis
  
### ✔️ Regional Performance

- Region-wise Sales distribution

- Region-wise Profit contribution

- High-performing regions identified (Central, South, North)

### ✔️ Product-Level Intelligence

- Top-selling products

- Product-wise contribution to Total Sales

- Category breakdown: Technology, Furniture, Office Supplies

### ✔️ Operational KPIs

- Average Delivery Delay

- Average Shipping Time

- Delayed Delivery % by Ship Mode

- Return % by Region

- Quantity shipped across global regions

## 🛠️ Tools & Technologies

- Power BI Desktop

- DAX for calculated measures

- Power Query for data transformation

- Dataset: Global Retail / Superstore dataset
